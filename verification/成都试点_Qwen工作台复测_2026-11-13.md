# 成都试点 Qwen 工作台复测

2026-11-13（北京时间）。隔离的 SQLite 测试账户通过工作台代理向 LangGraph 后端发送请求，后端经 SSH 转发调用 AutoDL 实例上的 Qwen3-8B。微调版主协调使用 V4 `epoch_2`，基座版主协调使用 `base`。两组的模型驱动专业角色都配置为 `base`，明确的试点预测检查由程序执行。

| 验收项 | Qwen 微调版 | Qwen 基座版 |
| --- | --- | --- |
| 初始化条件并生成 A/B 草案 | 通过 | 登记条件后直接比较，缺少生成草案的委派 |
| 只改预算、保留旧版并导出 | 通过 | 同时提交沿用字段，写入被原话校验拒绝 |
| 检查当前 A 的预测状态 | 通过 | 会话没有当前 A |
| 检查超预算 B | 通过 | 会话没有当前 B |
| 检查旧版 A | 通过 | 会话没有旧版草案 |

前三个预测检查分别核对未接通、超预算和旧版本等程序状态。测试用题由开发侧编写。基座版的三个预测检查依赖前面生成的草案，计数描述整条用户流程。后续团队独立问法仍待验证。

微调版另通过 4/4 连续改参用例。初始设置预算、面积上限和单价，再分别只改单价、只改面积上限、只改预算。工具记录确认每次只写入本轮指定字段，最终报告包含四个目标版本。

浏览器使用另一个独立账户，从地图进入试点，运行示例比较，再将预算从 10 万元改为 5 万元。页面显示候选 A 假设费用 43,200 元，候选 B 为 90,000 元并标为超预算。旧版保留，页面显示报告下载入口。「查看本轮依据」可追溯登记目标、委派方案探索和生成报告。

本机重新运行 V3 的离线栅格实验，结果与存档逐字段一致。A 的 144㎡全部与正高度像元重叠。B 有 140㎡与正高度像元重叠，剩余 160㎡高度缺测。假设 B 的缺测部分可改，估计为 32.996℃，相对模型基线 32.970℃高 0.027℃。这是该覆盖转换假设下的模型响应。A/B 可改范围和实际改造效果仍待现场及独立验证。 [离线实验记录](成都落图试点_V3地表温度情景实验.json) · [候选现场核查](../documentation/成都试点候选现场核查.md)
