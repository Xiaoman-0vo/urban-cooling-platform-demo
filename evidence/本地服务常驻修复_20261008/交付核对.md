# 本地网站停止问题修复核对

用户反馈网站经常自行关闭。本次检查确认 127.0.0.1:4173 没有监听服务，预览浏览器也没有保留标签。原启动入口将 Vite 作为终端前台进程运行，依赖启动窗口持续存在。没有历史退出日志，因此不将某一次过去的关闭归因于特定操作。

本次把启动入口改为由当前 macOS 用户登录会话独立托管服务。关闭启动窗口或聊天的临时执行会话后，服务继续运行。重复打开复用同一服务；异常退出由托管机制恢复。增加独立停止入口及运行日志。服务仅监听 127.0.0.1:4173，没有安装开机或登录自动启动项。

- 受控终止本项目进程后自动恢复，端点重新就绪。

运行边界：电脑关机、注销或重启会结束当前用户会话。下次双击启动本地平台.command 即可恢复服务。浏览器页面关闭与后台服务停止是两件事；服务在运行时可以重新打开同一地址。
