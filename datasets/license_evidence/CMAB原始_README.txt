These compressed files contain data and Python code to replicate the paper “CMAB: A First National-Scale Multi-Attribute Building Dataset Derived from Open Source Data and Ensemble Learning”. The data arise from a large-scale calculation, extraction and analysis of the buildings data in 3667 natural cities in China. The purpose is to use high remote sensing imagery, street view images and other multi-source data to estimate the multi-attributes of each buildings. 

Code:
The code records the codes used in the whole process, such as data labeling and training, rooftop semantic segmentation, calculation of different scale features of buildings, machine learning of height and function, fine-tuning CLIP, uncertainty estimation, geospatial process, statistical analysis and so on.

CMAB results:
The folder contains the results of the estimation of multi-attribute building dataset. The four rar files contain shapefiles  record buildings data for 3667 natural cities, including main cities in China, respectively. The attributes of the data are explained below and detailed in "Metadata.doc".
